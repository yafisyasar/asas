//Usage along with map(),reduce(),filter(),sort(),zip() - inbuilt functions
//map() is a built-in function.  It provides a concise and efficient way to perform transformations 
//on collections of data without explicitly writing a for loop.
//Syntax : map(fun, iter)
//fun : It is a function to which map passes each element of given iterable.
//iter : It is a iterable which is to be mapped.

//You can pass one or more iterable to the map() function.

//The returned value from map() (map object) then can be passed to functions like list() (to create a list), set() (to create a set) .

////////////////////////////////////////////////using map

#Using Lambda inside map

nums = [1, 2, 3, 4, 5]
square = list(map(lambda x: x**2, nums))
print(square)
#Output: [1, 4, 9, 16, 25]

/////////////////////////////////////////////

#reduce - The reduce() function starts with the first two elements of an iterable, applies the function to them, then uses the result with the next element. 
#This process continues until all elements are processed, resulting in a single cumulative value.

import functools

oldlist=[2,45,67,9,10]
prod=functools.reduce(lambda x,y:x*y,oldlist)
print(oldlist)
print(prod)

#Using reduce() with Operator Functions(without lambda) - Python’s operator module provides built-in functions, which are useful with reduce() to create cleaner code

#Filter
#The Python filter() function is a built-in function that allows you to filter 
#a sequence (e.g., a list, tuple, or set) based on a given condition.
#The function takes two arguments – a function and a sequence – and returns an iterator 
#containing elements from the original sequence for which the function returns True.

oldlist=[2,45,67,9,10]
newlist=list(filter(lambda x:(x%2!=0),oldlist))
print(newlist)

................................................................................

seq = [0, 1, 2, 3, 4, 5]

# result contains odd numbers of the list
result = filter(lambda x: x % 2 !=0, seq)
print(list(result))

# result contains even numbers of the list
result = filter(lambda x: x % 2 == 0, seq)
print(list(result))

............................................................................

a = [1, 2, 3, 4, 5, 6]

# First, filter even numbers
b = filter(lambda x: x % 2 == 0, a)

# Then, double the filtered numbers
c = map(lambda x: x * 2, b)

print(list(c))

.............................................................................

ages = [12, 17, 21, 30, 15]
adults = list(filter(lambda age: age >= 18, ages))
print(adults)

............................................................................

numbers = [-3, -1, 0, 2, 5]
print(list(filter(lambda x: x > 0, numbers)))

.............................................................................

values = ["apple", "", "banana", "", "cherry"]
cleaned = list(filter(None, values))
print(cleaned)  
# Output: ['apple', 'banana', 'cherry']

.............................................................................

scores = {"Alice": 85, "Bob": 42, "Cleo": 91}
passed = dict(filter(lambda item: item[1] >= 60, scores.items()))
print(passed)  # Output: {'Alice': 85, 'Cleo': 91}

map(): Transforms each element in the iterable based on the lambda expression
filter(): Selects elements that meet a condition.
reduce(): Combines elements into a single cumulative result.

#zip() - The `zip` function in Python is a built-in function that allows you to aggregate elements from multiple iterables into a single iterable. It takes two or more iterables as input and returns an iterator that produces tuples containing elements from all the input iterables.
Useful in student grades, employee salaries, product names & prices, etc.
Turning database columns & row values into dictionaries.

fruits = ['apple', 'banana', 'cherry']
colors = ['red', 'yellow', 'pink']

for fruit, color in zip(fruits, colors):
    print(fruit, color)

Output:
apple red banana yellow cherry pink
