Step 2: Define the Model (books/models.py)
We will create a database table to store book entries. Each book will have a title and a rating.

from django.db import models

class Book(models.Model):
    title = models.CharField(max_length=200)
    rating = models.IntegerField(default=5)

    def __str__(self):
        return f"{self.title} - {self.rating}/5 stars"


Step 3: Create the Form (books/forms.py)
Create a new file named forms.py inside the books/ folder. This form handles data validation (checking if rating is between 1 and 5):
Django uses a strict naming rule for validation functions: clean_<fieldname>(). Because this function is named exactly clean_rating, Django knows it must automatically run this code the moment a user clicks the "Submit" button on your web page.
When a user submits a form, Django first runs basic checks (e.g., making sure they actually typed a number and not random text like "hello"). If that basic check passes, it puts the value into a safe Python dictionary called cleaned_data. This line pulls that number out so we can inspect it.

from django import forms
from .models import Book

class BookForm(forms.ModelForm):
    class Meta:
        model = Book
        fields = ['title', 'rating']

    # Validation check: Ensure the rating is valid
    def clean_rating(self):
        rating = self.cleaned_data.get('rating')
        if rating < 1 or rating > 5:
            raise forms.ValidationError("Rating must be between 1 and 5 stars!")
        return rating



Step 4: Write the Controller Logic (books/views.py)
Open books/views.py and implement the view that lists existing books and processes the creation form:

from django.shortcuts import render, redirect
from .models import Book
from .forms import BookForm

def book_list(request):
    if request.method == 'POST':
        form = BookForm(request.POST)
        if form.is_valid():
            form.save()  # Saves validated book data directly to db.sqlite3
            return redirect('book_list')
    else:
        form = BookForm()

    # Retrieve all books from database
    books = Book.objects.all()
    return render(request, 'books/book_list.html', {'books': books, 'form': form})
