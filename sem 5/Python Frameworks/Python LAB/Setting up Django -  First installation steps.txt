Phase 1: Environment Setup & Project Initialization
Follow these steps in order to prepare your VS Code environment and generate the project backbone (myproject).
Step 1: Open Workspace and Set Execution Policy
Open VS Code, select File > Open Folder, and create or select your workspace folder. Open your terminal (Ctrl + ~) and run this command to allow script execution for your current session:
PowerShell
1 Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
Step 2: Create and Activate the Virtual Environment and update pip
Run the following commands to create a virtual environment named venv and activate it:
PowerShell
2 python -m venv venv
3 .\venv\Scripts\Activate
(You will notice a (venv) prefix appear on your terminal line, confirming you are safely isolated).
4 python -m pip install --upgrade pip
Ensures pip is updated to the latest version to avoid installation headaches.

Step 3: Install Django and Start the Project
Install Django via pip and initialize myproject directly at your workspace root:
PowerShell
5 pip install django
6 django-admin startproject myproject .
(Remember, the . at the end is crucial to keep your project files clean and unnested).

Phase 2: Building the Dashboard App (Root App)
This app will sit at the absolute root (/) and handle the central landing page.
Step 4: Create the Dashboard App Scaffold
Run this command in the terminal:
PowerShell
7 python manage.py startapp dashboardapp

Step 5: Write the Dashboard View (dashboardapp/views.py)
Open dashboardapp/views.py and paste this code. It will pull counts from the other two apps (which we will create right after this):
Python

from django.shortcuts import render
# We import these models now; they will become active once the other apps are built
from taskapp.models import Task
from profileapp.models import UserProfile

def home_view(request):
    total_tasks = Task.objects.count()
    total_profiles = UserProfile.objects.count()

    context = {
        'total_tasks': total_tasks,
        'total_profiles': total_profiles,
    }
    return render(request, 'dashboardapp/home.html', context)

Step 10: Write the Profile View (profileapp/views.py)
Open profileapp/views.py and implement the form processing and data fetching logic:
Python

from django.shortcuts import render, redirect
from .models import UserProfile

def profile_view(request):
    if request.method == 'POST':
        username = request.POST.get('username')
        bio = request.POST.get('bio')
        if username:
		UserProfile.objects.create(username=username, bio=bio)
        	return redirect('profile_view')

    profiles = UserProfile.objects.all()
    return render(request, 'profileapp/profile.html', {'profiles': profiles})

Step 14: Define the Task Model (taskapp/models.py)
Open taskapp/models.py and define your task table structure:
Python

from django.db import models

class Task(models.Model):
    title = models.CharField(max_length=200)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.title
Step 15: Write the Task View (taskapp/views.py)

Open taskapp/views.py and write your controller logic:
Python

from django.shortcuts import render, redirect
from .models import Task

def task_list(request):
    if request.method == 'POST':
        title = request.POST.get('title')
        if title:
            Task.objects.create(title=title)
            return redirect('task_list')

    tasks = Task.objects.all().order_by('-created_at')
    return render(request, 'taskapp/task_list.html', {'tasks': tasks})

Phase 5: Global Connection, Database Syncing & Launch
Now that all three individual apps are written, we register them inside the master settings, map their main URLs, sync our database tables, and turn on the server.
Step 18: Register All Apps (myproject/settings.py)
Open myproject/settings.py, scroll down to INSTALLED_APPS, and register your three new creations at the bottom of the list:
Python


INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'dashboardapp',  # Registered 1st
    'profileapp',    # Registered 2nd
    'taskapp',       # Registered 3rd
]

Step 19: Wire the Master Project URLs (myproject/urls.py)
Open myproject/urls.py and configure your global routing to give each app its proper prefix:
Python

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
path('admin/', admin.site.urls),
path('', include('dashboardapp.urls')),       # Dashboard handles root '/'
path('profile/', include('profileapp.urls')), # Profiles live on '/profile/'
path('task/', include('taskapp.urls')),       # Tasks live on '/task/'
]

Step 20: Run Migrations to Build Database Tables
Run these two commands in your terminal to process the database models for your profile and task apps into your SQLite database file:
PowerShell

python manage.py makemigrations
python manage.py migrate

Step 21: Run the Development Server
Fire up your ecosystem using:
PowerShell

python manage.py runserver

Open up your browser and visit [http://127.0.0.1:8000/](http://127.0.0.1:8000/). You can browse through your apps, add data to them, and watch your dashboard track it all in real-time!
